# Адаптация под футбольный news-фильтр MaxScore

**Статус:** план. Код MaxScore пока не меняем.  
**Дата:** 2026-09-29  
**Продукт:** [MaxScore](https://github.com/realReloadTime/MaxScore)  
**Этот репозиторий:** прототип агрегатора новостей (хакатон Т‑Банк, фондовый рынок).

## Зачем эта заметка здесь

MaxScore после soft launch (~10.10.2026) будет строить **полноценный news-фильтр** прогнозов.  
За основу архитектуры берём **этот** проект: не копируем тикеры акций, а переносим идею пайплайна.

Полный продуктовый план: в репо MaxScore файл  
`docs/GRILL_SOFT_LAUNCH_CORE_PLAN.md` (и ADR-005).

## Что уже есть в hackaton_tbank (полезно перенести как паттерн)

```
Источники (RSS / Telegram)
  → парсеры (Pasr/*.js)
  → обработка / классификация / (опционально) LLM-саммари
  → хранение (Postgres, Redis)
  → API (FastAPI) → клиенты
```

Стек по README: Python 3.10+, FastAPI, Postgres, Redis, aiogram, парсеры Node в `Pasr/`.

## Что нужно изменить под футбол

| Было (акции) | Будет (футбол MaxScore) |
|--------------|-------------------------|
| Тикеры SBER, LKOH… | Клубы / матчи / игроки (id SStats + RU-алиасы) |
| Торговый дайджест | Факты, влияющие на пик |
| Саммари «для трейдера» | Структурированное событие с типом из allowlist |
| Влияние на UI ленты новостей | **veto / downgrade** рекомендации (после soft launch) |

### Allowlist фактов v1 (могут трогать пик)

- ключевая травма / вне заявки  
- неожиданный состав  
- смена тренера  
- дисквалификация  
- перенос матча  
- турнирная санкция  

Слухи и мнения — **отдельная вкладка** у пользователя, в скоринг прогноза не идут.

## План работ (не путать с soft launch CORE)

1. **До 10.10:** только схема факта + spike одного футбольного источника **вне** прод-runtime MaxScore.  
2. **После 10.10:** сервис фактов → хук в пайплайн рекомендаций (veto/downgrade).  
3. Потом: вкладка «что говорят» на allowlist TG-каналов.

## Чего не делать из этого репо «как есть»

- Не тащить `node_modules` в MaxScore.  
- Не включать фондовые RSS без замены источников.  
- Не кормить сырой LLM-текст напрямую в генератор ставок.
